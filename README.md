# H+H releases

This repository contains public installers, signed update packages, release notes, and update metadata for H+H ceramic glaze research software.

Download a stable installer from [Releases](https://github.com/mmjdodd/H-H-Releases/releases). The first updater-enabled release requires a manual installation; subsequent versions can be installed from Settings → Software updates.

Source code, development history, and the original workbook are maintained in a separate private repository. This repository does not accept source archives or signing keys.

macOS packages may require approval in Privacy & Security until Apple Developer signing and notarization are configured. Ubuntu package updates request operating-system authorization.
